Privacy Policy

Effective November 19, 2026

This policy describes how Chopify Studio handles information when you create clips, connect a TikTok account, use Telegram Control Center, or visit this documentation site.

Video processing and local project data

Studio runs on your computer. It reads the media you select, transcribes speech with faster-whisper, analyzes audio and video for possible clips, and renders the clips you choose with FFmpeg. Local project files can include source paths or URLs, downloaded media, transcripts with timestamps, editing settings, analysis results, previews, exported videos, subtitle files, thumbnails, and job logs. A live session can also read public Twitch chat when chat capture is enabled and use it to derive activity signals.

Importing a URL or opening a live stream makes requests to the relevant source platform. The first use of a transcription model may download model files from Hugging Face. Optional Ollama features send text to the configured Ollama endpoint, which defaults to your computer. If you use campaign briefs, Studio may pass the brief and relevant transcript excerpts to the available or configured agent, such as Ollama, Claude, Codex, or Hermes. Whether that agent sends the text to a remote service depends on the agent and its settings.

Connecting a TikTok account

When you choose to connect, TikTok handles sign-in and consent on its own site. Studio receives an authorization code through a loopback address on your computer and exchanges it with TikTok for access and refresh tokens. Studio uses the developer credentials you set for the selected Sandbox or Production profile for token exchange, renewal, and revocation. On Windows, you may save these credentials and the resulting authorization in your user profile using Windows DPAPI. The authorization includes the access token, refresh token, expiry times, scopes, and app-specific account identifier. Studio can restore, verify, and renew a saved authorization. Temporary credentials and their tokens stay in process memory and require a new connection after restarting.

  • user.info.basic lets Studio read the TikTok account’s app-specific identifier and display name to identify the connected account.
  • video.upload lets Studio send an approved clip to the account’s TikTok inbox and ask TikTok for the upload or publication status.
  • video.publish is optional and requested only when the creator-information setting is enabled. Studio uses it to query available privacy options when TikTok grants the permission. The inbox workflow leaves the privacy selection and final publication to you in TikTok.

What Studio sends to TikTok

When you explicitly approve an upload, Studio sends the selected MP4 and upload information, such as the file size. Video, audio, and any captions already rendered into that MP4 travel with the file. The inbox upload request carries the MP4. Studio leaves the description for you to enter in TikTok. The project transcript and separate SRT file are outside that upload. TikTok handles uploads, drafts, and posts under its own policies. TikTok Privacy Policy

Publication history, storage, and disconnection

Studio saves publication records in the .tiktok-publications subfolder of your local projects directory. Entries can include the project and file identifiers, description, timestamps, a key derived from the TikTok account identifier and app key, TikTok’s publication identifier, status, and errors. Studio uses the account key to show the history for the corresponding connected account. Access and refresh tokens and signed upload URLs are kept out of the history.

Use Disconnect in Studio to request revocation from TikTok and clear the local session. If revocation cannot be completed, you can remove the local authorization from System Settings and revoke the app from your TikTok account settings. System Settings also lets you delete the stored developer credentials for each profile. Disconnecting leaves local project files and publication records on disk. Studio sets no automatic expiry for publication-history records. You can manage or remove the local files from your computer. For drafts or posts already sent to TikTok, use TikTok’s controls.

Telegram Control Center

When you enable the integration and pair your private Telegram chat, Studio connects to the Telegram Bot API from your computer. Telegram processes the messages, commands, and review choices you send through the bot. If you request a preview or enable automatic clip alerts, Studio sends the MP4 or a compressed review copy, rendered captions, editorial text, scores, and review metadata to that chat. Operational alerts can include the state of a capture or production job.

Studio saves the bot token in your Windows user profile using DPAPI. Its local database stores the paired user and chat identifiers, delivery status and errors. Review decisions and text edits are saved in the project workspace. Revoking pairing in Studio disables future access from the paired chat and cancels its pending deliveries. Messages that have already reached Telegram are managed through Telegram. Telegram Privacy Policy
